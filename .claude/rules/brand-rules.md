# Brand Rules — Jenny Kamprath for County Chair

## Design Principles
1. **Bold Asymmetry** — Layouts break the grid intentionally. Off-center compositions, overlapping elements, dramatic whitespace
2. **Patriotic Authority** — Deep navy + bold red anchor every composition. Strength, trust, American values
3. **Accessible by Default** — WCAG AAA contrast. Minimum 16px body text. Clear hierarchy
4. **Confident Simplicity** — Large type, strong imagery, purposeful spacing. No decoration without purpose

## Color System

### Primary
- Navy 900: `#0D1B2A` — Hero backgrounds, headers, primary text
- Navy 800: `#1A2744` — Logo text, headings, dark sections
- Navy 700: `#1B3A5C` — Secondary dark, accent backgrounds
- Navy 600: `#264D73` — Decorative dark accents
- Patriot Red: `#C41E3A` — CTAs, logo accent, highlights, links
- Red Dark: `#9E1830` — Hover states, pressed buttons
- Red Light: `#E8546A` — Decorative accents on dark backgrounds

### Neutral
- White: `#FFFFFF`
- Off-White: `#F8F9FA` — Page backgrounds, section alternation
- Warm Gray 50: `#F5F3F0` — Card backgrounds, form fields
- Warm Gray 100: `#E8E4DF` — Borders, dividers
- Warm Gray 200: `#D4CEC6`
- Warm Gray 400: `#9C958C` — Captions, meta text
- Warm Gray 600: `#6B6560` — Body text, descriptions
- Warm Gray 800: `#3A3632` — Strong body text

### Accent
- Coral: `#F6483D`
- Gold: `#C9A84C`
- Sky: `#4A90D9`

## Typography
- **Display font**: Playfair Display (serif) — Headlines, hero text, card titles
- **Body font**: Montserrat (sans-serif) — Body text, nav, buttons, labels
- **Type scale**: H1=56px/1.08, H2=42px/1.15, H3=32px/1.2, H4=24px/1.3, H5=18px/1.4, Body=16px/1.65, Caption=14px/1.5
- Minimum body text: 16px
- Minimum touch target: 44px

## Layout Rules
- Max container width: 1290px
- Section vertical padding: 96–128px
- 8px base spacing grid
- Asymmetrical splits: 55/45 or 60/40 default
- Border radius: 8px (buttons), 16px (cards)

## Signature Design Patterns
1. **Floating circle accents** — Semi-transparent circles with 1px white borders on dark sections
2. **Right edge stripe** — 8px dual-tone vertical stripe (40% red top, 60% navy bottom)
3. **Background watermark text** — 120-160px at 4-8% opacity behind content
4. **Navy gradient overlays** — 75-85% opacity over hero images

## Button Specs
- Primary: Patriot Red bg, white text, 8px radius
- Secondary: Transparent, navy border, 8px radius
- Font: Montserrat SemiBold 16px

## Header Specs
- Height: 72px
- Background: Navy 900 solid or transparent with blur over hero
- Logo: Playfair Display 900 18px — "JENNY" in Patriot Red, "KAMPRATH" in white
- Nav: Montserrat 500 13px uppercase, 1px letter-spacing
- CTA: Patriot Red bg, 6px radius

## Photography
- Natural lighting, warm color temperature
- Eye-level or slightly below
- Oregon/Idaho landscapes as hero backgrounds
- Candid over posed
- Navy 900 gradient overlay at 75-85% for text overlays
